# 🎬 BobCI Demo Video Script
## 3-4 Minute Screen Recording Guide

---

## 📋 Pre-Recording Checklist
- [ ] Backend running on http://localhost:8000
- [ ] Frontend running on http://localhost:3000
- [ ] Demo data seeded (3 PRs visible)
- [ ] Browser window maximized, zoom 100%
- [ ] Close unnecessary tabs
- [ ] Disable notifications
- [ ] Test microphone
- [ ] Have GitHub repo link ready

---

## 🎥 RECORDING SCRIPT

### [0:00-0:15] INTRODUCTION
**SCREEN:** Show GitHub PR with many comments, then transition to BobCI logo
**SPEAK:** 
> "Every day, developers wait hours for code reviews. Security issues slip through. Junior developers struggle with complex changes. What if AI could review every pull request in seconds?"

---

### [0:15-0:30] SOLUTION INTRO
**SCREEN:** Show BobCI dashboard loading
**SPEAK:**
> "Introducing BobCI - an AI-powered pull request intelligence system. Built with IBM Bob and watsonx.ai, it analyzes code in under 6 seconds."

---

### [0:30-0:50] DASHBOARD OVERVIEW
**SCREEN:** Dashboard at http://localhost:3000
**ACTION:** Point to the 3 PR cards
**SPEAK:**
> "Here's the BobCI dashboard. We have three pull requests. Notice the risk badges - Critical, Medium, and Low. Let's look at this critical one."

**ACTION:** Click on PR #42 "Add API key authentication"

---

### [0:50-1:20] MERGE SAFETY SCORE
**SCREEN:** PR detail page showing Merge Safety Score
**ACTION:** Point to the animated score circle (23/100)
**SPEAK:**
> "BobCI calculates a Merge Safety Score. This PR scores 23 out of 100 - that's CRITICAL. The score comes from seven AI agents analyzing different aspects: security, testing, documentation, and more."

**ACTION:** Scroll down to show the risk factor breakdown

---

### [1:20-1:50] SECURITY VULNERABILITIES
**SCREEN:** Click on "Security" tab
**ACTION:** Scroll through the vulnerability list
**SPEAK:**
> "The Security Agent found six vulnerabilities. Three are critical - SQL injection, hardcoded API keys, and weak password hashing. But BobCI doesn't just find problems - it shows you how to fix them."

**ACTION:** Expand one vulnerability to show before/after code
**SPEAK:**
> "See? Here's the vulnerable code, and here's the secure version. Every fix is ready to copy and paste."

---

### [1:50-2:20] IMPACT RADIUS
**SCREEN:** Click on "Impact Analysis" or "Impact Radius" tab
**ACTION:** Show the dependency graph visualization
**SPEAK:**
> "The Impact Agent built a dependency graph. One file changed, but look at the blast radius - ten files are affected. Red nodes are breaking changes, orange are direct impacts. This is why the risk is so high."

**ACTION:** Hover over nodes to show details

---

### [2:20-2:40] RISK HEATMAP
**SCREEN:** Click on "Risk Heatmap" tab
**ACTION:** Show the color-coded file list
**SPEAK:**
> "The Risk Heatmap shows which files have the most vulnerabilities. Red means critical issues, yellow means warnings. This helps you prioritize what to fix first."

---

### [2:40-3:10] JUNIOR DEVELOPER GUIDE
**SCREEN:** Click on "Junior Guide" tab
**ACTION:** Scroll through the explanations
**SPEAK:**
> "For junior developers, BobCI's Mentor Agent, powered by watsonx.ai, explains everything in simple terms. SQL injection is explained like a vending machine bug. Hardcoded secrets are like writing your ATM PIN on your card. Real-world analogies make learning easy."

**ACTION:** Show code examples in the guide

---

### [3:10-3:25] BOB IDE PROOF
**SCREEN:** Switch to show Bob IDE or bob_sessions folder
**SPEAK:**
> "All of this is powered by IBM Bob. Here's proof - Bob sessions stored locally, showing the AI analysis in action. Bob understands your entire codebase and provides context-aware insights."

**ACTION:** Show bob_sessions folder or Bob IDE interface briefly

---

### [3:25-3:45] FEATURES RECAP
**SCREEN:** Go back to dashboard, scroll through PRs
**SPEAK:**
> "Let's recap. BobCI gives you: instant security scanning, predictive failure analysis, automated test generation, documentation quality checks, and AI-powered mentoring. All in under 6 seconds per pull request."

---

### [3:45-4:00] CLOSING
**SCREEN:** Show GitHub repository page or README
**SPEAK:**
> "BobCI is open source and production-ready. Built with IBM Bob and watsonx.ai. Check out the GitHub repository for setup instructions and documentation. Transform your code review process today."

**ACTION:** Show GitHub repo link on screen
**TEXT OVERLAY:** 
```
github.com/yourusername/bobci
Built with IBM Bob + watsonx.ai
```

## 💡 SPEAKING TIPS

### Pace
- Speak slowly and clearly
- Pause after important points
- Let animations complete before speaking

### Tone
- Confident and professional
- Enthusiastic but not rushed
- Friendly and approachable

### Pronunciation Guide
- **BobCI**: "Bob C I" (three syllables)
- **watsonx.ai**: "Watson X dot A I"
- **SQL**: "S Q L" or "sequel"
- **API**: "A P I"

```bash

npm run dev
```

- Close other applications
- Reduce browser zoom to 90%
- Record in shorter segments
